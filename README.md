# NFM-X: Non-Forgettable Memory Layer

![NFM-X Logo](https://img.shields.io/badge/NFM--X-Memory%20Layer-blue)
[![Python](https://img.shields.io/badge/python-3.10%2B-green)](https://www.python.org/)

[![Status](https://img.shields.io/badge/status-Active-brightgreen)](https://github.com/abdulraheemnohri/NFM-X)

**NFM-X** is a production-grade, model-independent, local-first long-term memory layer for AI systems.

## Features

- Memory CRUD with versioning
- Hybrid search (semantic + keyword)
- Context building for LLM prompts
- Python SDK
- CLI interface

## Installation

```bash
pip install -r requirements.txt
uvicorn backend.app.main:app --reload
```
