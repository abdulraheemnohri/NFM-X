# NFM-X Frontend

React Dashboard for NFM-X: Non-Forgettable Evolutionary AI Memory System

## Features

- Memory Management: Create, read, update, and delete memories
- Advanced Search: Semantic, keyword, temporal, graph, and hybrid search
- Knowledge Graph: Visualize memory relationships
- Analytics Dashboard: Statistics and insights
- Multi-language Support: English and Urdu
- Responsive Design: Works on all devices
- PWA Support: Installable as a Progressive Web App

## Prerequisites

- Node.js 18+
- npm or yarn
- NFM-X Backend running

## Installation

cd NFM-X/frontend
npm install
npm start
